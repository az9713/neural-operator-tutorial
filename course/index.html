How to use this course

Each module is one HTML page and, where a lab exists, one notebook in ../notebooks/. A page has the same six parts in the same order: why the module exists, the core ideas in prose, the mathematics with derivations, the lab with real numbers, the sources with line citations, and an exit test. Do the exit test with the page closed. If you cannot pass it, reread the section it names.

Three objectives run through the whole course and must not be mixed. A surrogate reproduces a known simulator faster. A PINN uses the equation as a loss to fit one solution. A foundation model tries to reuse one representation across several physical systems. Success at one does not prove success at another. Module 0 fixes this vocabulary. Module 10 tests the third objective with an experiment that can fail.

The theory plan of 4 September 2026 (a private theory study plan (not in this repository)) is absorbed into this course. Its proofs sit in Modules 0, 1, 2, 3, 4, and 5. The mapping is decision 2 of the project notes (not in this repository).

The labs

Three labs already ran and their numbers are on the pages. The rest are specified in full on their module page and in the notebooks, and are marked "not yet run".

Lab 01, Burgers (ran)

../labs/01_burgers/. Run A: the bundled 16 point space time data through the library's own loader and Trainer. Run B: the ICLR/JMLR paper spec (ν = 0.1 on (0, 2π)) with a solver written and checked in the same file, trained at 64 points, evaluated at 64, 128, 256, 1024.

Lab 02, die thermal (ran)

../labs/02_thermal/. Steady heat conduction in a 10 mm silicon die with random rectangular power blocks. Finite difference truth checked against an analytic solution. FNO trained at 64², evaluated at 64² and 128², with hot spot error in kelvin.

Lab 03, scale (ran)

../labs/03_scale/. One 2D FNO forward pass at 64² to 1024² with n_modes 16 and 64: peak memory and time per grid, then the arithmetic to 1000³. Numbers in Module 9.

Evidence grades used on every page

A read in the primary paper, page cited. B abstract or secondary source only, arXiv identifier verified. C company statement, press, or podcast; not independently checked. LAB produced in this folder; script, seed, and results file cited.
