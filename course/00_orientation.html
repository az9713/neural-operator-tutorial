Why this module exists

The seed video (Latent Space, 4 September 2026, KS_IpnX7n9I) says three things in its first five minutes: neural operators replace simulators, physics laws give dense feedback, and one model can learn many physical systems. Those are three different claims with three different tests. The earlier episode (79mIutht1f4, 26 August 2026) explains the first claim well between 00:16:12 and 00:19:07 and the reason PINNs fail between 00:11:58 and 00:14:04. Neither episode separates the three claims. This module does.

Surrogate. A model that reproduces a known simulator faster. Test: error against the simulator on held out inputs, plus speed. PINN. A model that fits one solution by penalizing the equation residual. Test: residual and error on one instance. Foundation model. A model that reuses one representation across several physical systems. Test: does pretraining on systems A and B lower the data needed for system C, against an equal size model trained on C alone? Success at one does not prove success at another. The course returns to this split in Module 10.

Core ideas

Four words

A function maps a point to a value: \(x \mapsto u(x)\). An operator maps a whole function to a whole function: \(f \mapsto u\). The map "initial condition in, solution at time one out" is an operator. So is "heat source map in, temperature field out", which Lab 02 uses. A function has infinitely many degrees of freedom. A computer stores finitely many samples or coefficients. A discretization is that finite record: a set of points \(D_L = \{x_1, \dots, x_L\}\) and the values \(a(x_\ell)\). A learned operator is a parametric map \(G_\theta\) that is defined on functions and that we only ever evaluate through discretizations.

Keep the following order of questions. First, representation: does a good approximating model exist at all? Second, learning: what can a finite sample of input output pairs determine? Third, discretization: how does the finite model on a grid relate to the continuum object? Training is a fourth problem, optimization, that sits on top. The JMLR paper lists exactly these four sources of error on pages 50 to 51 and proves results for only two of them (research_notes/pdf-fno-jmlr.md:705-711). Module 5 makes that ledger precise.

"Resolution is context length", stated exactly

The company episode sells resolution invariance as flexible context length. The exact claim, from the earlier episode at 00:16:12 to 00:17:51: standard networks have fixed size inputs and outputs, neural operators model inputs and outputs as continuous functions, so they accept and produce data at any resolution. What that does and does not mean is the whole of Module 1. The short version: a fixed parameter set can be evaluated on any grid, and the output converges to one continuum operator as the grid refines. It does not mean accuracy is guaranteed at a grid you never trained on. That needs assumptions about unresolved content, which Module 1 states and Lab 01 tests.

Why not PINNs, in one paragraph

A PINN solves one instance by optimization. The loss landscape becomes ill conditioned as the equation gets harder. Krishnapriyan et al. show a standard PINN on the convection equation \(u_t + \beta u_x = 0\) reaches about 100 percent relative error once \(\beta\) exceeds about 10, with a condition number that scales like \((\beta N)^2\) (research_notes/web-papers.md:600-616). The failure is optimization, not capacity. Anandkumar's version of the same point is at 00:11:58 to 00:14:04 in the earlier episode. Module 4 gives the numbers and the two fixes.

Mathematics: function spaces and what finite observations preserve

You need three facts from functional analysis for the rest of the course. Each is proved here in the smallest setting that shows the mechanism.

Fact 1. An \(L^2\) element has no point values

The precise statement is this: there is no rule that takes an element of \(L^2(0,1)\) and a point \(x_0\) and returns "the value there". Every dataset in this course is a table of point values, so the fact needs its argument, not an assertion. This subsection does four things. It says what the space is and why its elements are equivalence classes and not functions. It proves that evaluation is not defined on a class, and that it is not even continuous on the functions where it is defined. It proves the rescue: enough smoothness gives a class exactly one continuous representative, and in \(d\) dimensions the threshold is \(s > d/2\) derivatives. It ends with the three routes around the problem, and where this course uses each one.

Why the elements are classes

Start with the raw material: measurable \(u : (0,1) \to \mathbb R\) with \(\int_0^1 |u|^2\,dx < \infty\). The candidate norm is \[\|u\|_2 = \Big(\int_0^1 |u|^2\,dx\Big)^{1/2}.\] It is homogeneous and it obeys the triangle inequality. It fails one axiom. The function that is 1 at \(x = 1/2\) and 0 elsewhere has \(\|u\|_2 = 0\) and is not the zero function. So \(\|\cdot\|_2\) is a seminorm, and \(d(u,v) = \|u - v\|_2\) is a pseudometric: two different objects sit at distance zero from each other.

That is fatal, not untidy. In a pseudometric space limits are not unique, so "the" limit of a Cauchy sequence has no meaning, and neither does "the" orthogonal projection that Fact 3 needs. The repair is forced: collapse everything at distance zero into one object. Declare \(u \sim v\) when \(\|u - v\|_2 = 0\), and let \(L^2(0,1)\) be the set of classes. Only then is \(\|\cdot\|_2\) a norm; only then is the space complete (Riesz-Fischer) and a Hilbert space with an orthonormal basis. Facts 2 and 3 spend that structure. Fact 1 is its bill.

Null sets. \(N \subset \mathbb R\) is null if for every \(\varepsilon > 0\) there are countably many intervals \(I_1, I_2, \dots\) with \(N \subset \bigcup_n I_n\) and \(\sum_n |I_n| < \varepsilon\). One point \(x_0\) is null: cover it by \((x_0 - \varepsilon/4,\, x_0 + \varepsilon/4)\), of length \(\varepsilon/2\). The rationals in \((0,1)\) are null: enumerate them \(q_1, q_2, \dots\) and cover \(q_n\) by an interval of length \(\varepsilon 2^{-n-1}\), for a total of \(\varepsilon/2\). A null set can therefore be dense. It need not be countable either; the Cantor set is uncountable and null.

Claim. \(\|u\|_2 = 0\) if and only if \(u = 0\) outside a null set. That condition is written "\(u = 0\) almost everywhere", abbreviated a.e.

Proof. If \(u = 0\) off a null set, then \(|u|^2 = 0\) off that set, and the Lebesgue integral of a function that vanishes off a null set is zero. Conversely, let \(A_n = \{x : |u(x)| > 1/n\}\). On \(A_n\) the integrand exceeds \(1/n^2\), so \(0 = \int_0^1 |u|^2 \ge n^{-2}\,|A_n|\), which forces \(|A_n| = 0\) for every \(n\). The set where \(u \ne 0\) is \(\bigcup_n A_n\), a countable union of null sets, which is null. \(\square\)

Consequence. \(u \sim v\) means exactly \(u = v\) a.e. In \(L^2(0,1)\) the zero element and the indicator function of the rationals are the same element, although they differ at every rational, a dense set of points.

Evaluation is not defined, and not continuous

Claim 1 (evaluation carries no information). Fix any \(x_0 \in (0,1)\) and any number \(c\). Every element of \(L^2(0,1)\) has a representative whose value at \(x_0\) is \(c\).

Proof. Take any representative \(u\) and set \(\tilde u(x) = u(x)\) for \(x \ne x_0\), \(\tilde u(x_0) = c\). Then \(\tilde u - u\) vanishes off \(\{x_0\}\), a null set, so \(\tilde u \sim u\). \(\square\)

So \(u(x_0)\) is not merely ambiguous for awkward functions. Any value at all can be arranged, for every element, at every point. A model that reads an \(L^2\) input by sampling reads a property of the representative that the modeller happened to write down, not a property of the element.

Claim 2 (evaluation is unbounded). Restrict to continuous functions, where \(u(x_0)\) is unambiguous. There is still no constant \(C\) with \(|u(x_0)| \le C\|u\|_2\) for all of them.

Proof. Take the tent \(t_n(x) = \max(0,\, 1 - n|x - x_0|)\), which is continuous, peaks at \(t_n(x_0) = 1\), and is supported in an interval of width \(2/n\). Then \[\|t_n\|_2^2 = \int_{-1/n}^{1/n} (1 - n|s|)^2\,ds = 2\int_0^{1/n}(1 - ns)^2\,ds = \frac{2}{3n},\] so \(\|t_n\|_2 = (2/3n)^{1/2} \to 0\) while \(t_n(x_0) = 1\) for every \(n\). No \(C\) survives. \(\square\)

Consequence. \(t_n \to 0\) in \(L^2\). A learner that reads its input by point sampling can be handed a sequence of inputs that converges to zero in the very norm its error is measured in, while one of the numbers it reads never moves. Evaluation is not only undefined on classes; it is discontinuous on the functions where it is defined. Module 1 measures the quantitative form of this on a grid, where it is called aliasing.

One honest caveat. The Lebesgue differentiation theorem does give every class a canonical value at almost every point: the limit of its averages over shrinking intervals around that point. "Almost every" is the catch. The exceptional null set depends on the element, so no fixed grid of sample points is safe for every input, and a fixed grid is what a trained model has.

The rescue: half a derivative buys the point value back

Claim 3 (a continuous representative is unique). If two continuous functions on \([0,1]\) agree a.e., they agree everywhere. So a class that has a continuous representative has exactly one, and evaluating that representative is a well defined operation on the class.

Proof. Let \(w\) be continuous and zero off a null set \(N\). Suppose \(w(x_0) \ne 0\). By continuity there is an interval \(I\) around \(x_0\) on which \(|w| > |w(x_0)|/2 > 0\), so \(I \subset N\). An interval of positive length is not null, and no subset of a null set has positive length. Contradiction. \(\square\)

Claim 4 (which spaces have that property). Work on the torus \(\mathbb T^d\), with Module 1's norm \(\|u\|_{H^s}^2 = \sum_k (1 + |k|^2)^s |\hat u(k)|^2\). If \(s > d/2\), then every \(u \in H^s(\mathbb T^d)\) has a continuous representative, and \[\sup_x |u(x)| \le C_s\,\|u\|_{H^s}, \qquad C_s = \Big(\sum_k (1 + |k|^2)^{-s}\Big)^{1/2} < \infty .\]

Proof. Split each Fourier coefficient and apply Cauchy-Schwarz: \[\sum_k |\hat u(k)| = \sum_k (1+|k|^2)^{s/2}|\hat u(k)| \cdot (1+|k|^2)^{-s/2} \le \|u\|_{H^s}\Big(\sum_k (1+|k|^2)^{-s}\Big)^{1/2}.\] The last sum converges exactly when \(2s > d\): compare it with \(\int_{\mathbb R^d}(1+|\xi|^2)^{-s}\,d\xi\), whose integrand decays like \(|\xi|^{-2s}\) while the shell volume grows like \(|\xi|^{d-1}\). So \(\sum_k |\hat u(k)| < \infty\), the Fourier series converges uniformly by the Weierstrass M-test, and a uniform limit of continuous functions is continuous. That sum agrees with \(u\) in \(L^2\), hence a.e., so it is the continuous representative, and the displayed inequality bounds its supremum. \(\square\)

Consequence. In one dimension the threshold is \(s > 1/2\). Evaluation is unbounded on \(H^0 = L^2\) and bounded on every \(H^s\) with \(s > 1/2\). The price of a point value is half a derivative. In two dimensions, as in Lab 02, the price is one derivative.

The three routes around Fact 1

  1. Assume the inputs are smooth enough. This is the hypothesis of JMLR Theorem 8, word for word: the input and output spaces must be Banach function spaces "continuously embeddable in \(C(\bar D)\)" (p.54, research_notes/pdf-fno-jmlr.md:467-468). The proof samples on a grid and passes to Riemann sums, which is legitimate only when point values exist. Discretization invariance is bought with that assumption.
  2. Never sample; read the input through integrals. The universal approximation theorems allow far rougher inputs. Assumption 9 lets the input space be \(L^{p}(D)\) for \(1 \le p < \infty\) (p.55, research_notes/pdf-fno-jmlr.md:477-478). The mechanism is Lemma 28 (p.81): every bounded linear functional on \(W^{m,p}(D)\), which is \(L^p\) when \(m = 0\), is approximated uniformly on a bounded set by \(u \mapsto \int_D \kappa u\,dx\) with a smooth compactly supported \(\kappa\). Lemma 30 (p.86) proves the same on \(C(\bar D)\), and it goes through Lemma 29 (p.85), which first writes the functional with point evaluations. It may do that because on \(C(\bar D)\) point evaluation is bounded. Put the two lemmas side by side and you are reading Fact 1 in the paper's own hands.
  3. Sample an average, not a value. A cell average is \(\int \kappa u\) with \(\kappa\) the indicator of the cell divided by its area: route 2, in code. Lab 02 needs it. Its input is a set of power rectangles, so it is discontinuous and route 1 is closed. The down-sampler therefore block-averages instead of picking a value, "so that a rectangle edge between cells is represented by its area fraction" (../labs/02_thermal/run_thermal.py:92-95). A finite volume solver hands you route 3 whether you asked for it or not, because its unknowns are cell averages.

Where this decides something in this course. Lab 01's Burgers initial condition has \(|\hat u_k|\) falling like \(k^{-2}\) (Module 1). Then \(\sum_k (1+k^2)^s |\hat u_k|^2\) behaves like \(\sum_k k^{2s-4}\), which is finite for \(s < 3/2\). Since \(3/2 > 1/2\), those inputs do have continuous representatives, so reading them off a grid is legitimate and route 1 applies. What remains is not Fact 1 but aliasing, and Module 1 puts a number on it: about 0.5 percent of the initial condition's energy sits above \(k = 32\).

The FNO paper's Darcy benchmark is the other case. Its coefficient \(a\) takes two values, 12 and 3, on a random partition, and the reference solution is computed on a 421 by 421 grid (research_notes/pdf-fno-jmlr.md:108-112). A two valued field has no continuous representative, so its natural space does not embed in \(C(\bar D)\), and Theorem 8 as stated does not cover that input space. The theorems that do cover it are the universal approximation family, whose Assumption 9 admits \(L^p\), and they read the input by route 2. Fact 1 is what separates the paper's two hypothesis sets.

The experiment then does what the theorem does not license: it point samples. The paper builds every coarser Darcy grid by subsampling the 421 by 421 data (p.32), and the FNO error stays flat, 0.0108 at 85 points per side and 0.0098 at 421 (research_notes/pdf-fno-jmlr.md:121). The reason is worth stating, because it is Fact 1 used in the other direction. A two valued field does have a point value at every location off the interfaces between the phases, and those interfaces are curves, a set of zero area. A sample is therefore exact unless its cell straddles an edge, and the area that is misread shrinks as the grid refines. The failure Fact 1 warns about is real but is confined to a set whose measure goes to zero. A field with no such structure, for example one that oscillates at every scale, gives no such reprieve.

Module 4 turns the same fact on DeepONet, whose branch network reads the input at fixed sensor locations. That is point evaluation, so the sensor reading means something only under the smoothness assumption of route 1.

Fact 2. Bounded sets are not compact in infinite dimensions

Take an orthonormal sequence \((e_j)\) in a Hilbert space. Then \(\|e_j - e_k\|^2 = \|e_j\|^2 + \|e_k\|^2 - 2\langle e_j, e_k\rangle = 2\) for \(j \ne k\). No subsequence is Cauchy, so none converges. The unit ball is bounded and closed but not compact. In finite dimensions Heine-Borel makes closed and bounded enough, which is why finite dimensional approximation results carry no such hypothesis. In infinite dimensions the ball has room for infinitely many points that stay \(\sqrt 2\) apart, so it has no finite \(\varepsilon\)-net for \(\varepsilon < \sqrt2/2\). The finite net is the one tool every proof on this page uses, and on the ball it has nothing to grip. Every approximation theorem in this course therefore quantifies over a compact set of inputs \(K\), never over the whole ball. Module 5 shows what breaks when you forget this.

Fact 3. Projections converge pointwise, not in norm

Let \((e_j)\) be an orthonormal basis of a separable Hilbert space \(H\) and \(P_m u = \sum_{j \le m} \langle u, e_j\rangle e_j\).

Claim. \(P_m u \to u\) for every \(u \in H\), but \(\|I - P_m\| = 1\) for every \(m\).

Proof. Parseval gives \(\|u - P_m u\|^2 = \sum_{j > m} |\langle u, e_j\rangle|^2\), the tail of a convergent series, so it goes to zero. For the norm, \(\|I - P_m\| \le 1\) because \(I - P_m\) is an orthogonal projection. Take \(u = e_{m+1}\): then \((I - P_m)e_{m+1} = e_{m+1}\), so the norm is at least 1. \(\square\)

Consequence. "Truncate to \(m\) modes" has no uniform error bound on the unit ball. It has one on any compact \(K\): cover \(K\) by finitely many balls of radius \(\varepsilon\) around centres \(u_1, \dots, u_n\), choose \(m\) so that \(\|u_i - P_m u_i\| < \varepsilon\) for all \(i\), then for any \(u \in K\) with \(\|u - u_i\| < \varepsilon\), \[\|u - P_m u\| \le \|u - u_i\| + \|u_i - P_m u_i\| + \|P_m(u_i - u)\| < 3\varepsilon .\] This is the pattern of every discretization invariance proof: a finite net on a compact set, plus a uniform bound on the operator.

Why this matters for FNO. An FNO keeps \(k_{\max}\) Fourier modes in each layer. Fact 3 says that truncation alone has no uniform accuracy on all inputs, only on inputs whose spectra decay in a controlled way. Lab 01 makes the spectra visible. The FNO paper's own answer, that the nonlinearity regenerates high modes, is on research_notes/pdf-fno-jmlr.md:178-184 and is examined in Module 2.

The destination example

The course returns to one operator again and again: \(-u'' = f\) on \((0,1)\) with \(u(0) = u(1) = 0\). It is linear, it smooths (one derivative in, three out in the classical sense), and it has an explicit kernel. As a map it sends \(L^2(0,1)\) to \(H^2(0,1) \cap H^1_0(0,1)\). Module 3 derives its Green's function and its spectrum. The JMLR paper's first experiment learns exactly this operator to relative error \(10^{-7}\) with a zero hidden layer neural operator (research_notes/pdf-fno-jmlr.md:537-545).

The 90 minute diagnostic

Answer without references. An incomplete answer tells you what to review. It says little about whether you can learn the subject.

  1. Explain why \(L^2\) contains equivalence classes and why \(u(x_0)\) is not defined on an arbitrary element.
  2. Give a bounded sequence in a Hilbert space with no norm convergent subsequence. State what this implies for closed bounded sets in infinite dimensions.
  3. Derive the Fourier multiplier for periodic heat evolution on the unit torus. Say what it does to high frequencies and why inversion is unstable.
  4. Write the weak formulation of \(-\nabla\cdot(a\nabla u) = f\) with zero Dirichlet data. State the assumptions that give existence, uniqueness, and a stability estimate.
  5. Distinguish pointwise convergence of operators, uniform approximation on a compact input set, and convergence in operator norm.

What a satisfactory answer contains. (1) Functions equal almost everywhere are the same element; changing one value changes no norm; and the rescue, that a class with a continuous representative has exactly one, which \(H^s\) with \(s > d/2\) guarantees. (2) An orthonormal sequence has pairwise distance \(\sqrt 2\). (3) On the unit torus the multiplier is \(\exp(-4\pi^2\kappa t|k|^2)\) for \(\kappa > 0\); it damps high \(k\) exponentially, so inverting it amplifies noise at high \(k\) exponentially. (4) A bounded Lipschitz domain, \(a \ge \alpha > 0\) bounded, \(f \in H^{-1}\), trial and test space \(H^1_0\), a bounded coercive bilinear form, Lax–Milgram. (5) The order of the quantifiers and the set the supremum runs over. Module 1 proves (4). Module 2 derives (3).

Pacing rule. If 1, 2, and 5 are easy, take Module 1 in four days. If 4 is unfamiliar, give Module 1 a second week. Fluency with the Fourier transform does not imply comfort with Sobolev spaces or spectral approximation estimates; do not skip Module 1 on that basis.
